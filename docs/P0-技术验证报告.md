### Spike B — Redis 8 向量检索 ✅ 实跑通过
- 实测（128 维 / 100 条 / COSINE）：

| 索引 | 写入 100 条 | KNN Top5 查询 | Top1 自命中 |
|------|------------|---------------|--------------|
| FLAT | 32 ms | 16 ms | ✅ |
| HNSW | 33 ms | <1 ms | ✅ |

- 结论：Redis 8 向量检索可用；数据规模小，两种索引精度一致，**默认选 HNSW**（查询快、可扩展）。
- Jedis 5.2.0 新 API：`schemafields.VectorField` + `VectorAlgorithm`（与旧 `Schema.VectorField` 不兼容，已按新 API 实现）。

### Spike C — Docker Python 沙箱 ✅ 实跑通过
- 三项全过：

| 场景 | 结果 | 耗时 |
|------|------|------|
| 正常执行（stdout 回传 JSON） | exit=0，输出完整 | 774 ms |
| 超时强杀（sleep 600，限 5s） | timeout=true，容器被 kill | 5.4 s |
| 网络隔离（访问外网） | NETWORK_BLOCKED | — |

- 资源限制生效：`--network none --memory 512m --cpus 1`，容器 `--rm` 用完即毁，**实测零残留**。
- **重要技术决策**：沙箱客户端改用 **docker CLI（ProcessBuilder）** 而非 docker-java。
  原因：docker-java 3.4.2 的 httpclient5 传输层不支持 Windows npipe（本机 Docker Desktop
  管道为 `dockerDesktopLinuxEngine`，连接报 `npipe://localhost:2375 refused`）。
  CLI 方案天然适配任意宿主机通道（npipe/unix socket/TCP），零原生依赖；
  `PythonSandboxClient` 接口保持稳定，后续如需可平滑替换为长连接客户端。
